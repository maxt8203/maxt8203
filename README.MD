## Featured: [agent-lanes](https://github.com/maxt8203/agent-lanes)

**Run a team of Claude Code agents on one project, with the rules enforced in code rather than just written in prompts.**

  <img width="600" alt="agent-lanes: four layers from human to coordinator to build chats to lanes" src="https://github.com/user-attachments/assets/5d90811f-079c-4e78-9b7c-17d536165ba7" />

- **Layered agent team:** a human in charge, a coordinator agent, one build agent per area of the app, and parallel subagent "lanes" (coder, researcher, tester, critic)
- **Guardrails as code:** hooks block agents from editing each other's files, shared tools are locked to one user at a time with timeouts and a queue, and messages reach every agent automatically
- **Three quality gates:** AI test, then a sceptical critic agent, then human sign-off, enforced in that order by the CLI
- **Easy to start:** one-line install, `./crew up` opens the whole team, and a guided demo job runs end to end
- **Built to last:** no dependencies (standard-library Python + Bash), 19 automated tests, CI on macOS and Linux

`Python` · `Claude Code hooks & subagents` · `Bash` · `GitHub Actions`
